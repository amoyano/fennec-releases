# Fennec for Mac

Official installers for Fennec. Requires macOS 14 or later and Apple Silicon.

Download the latest DMG from [Releases](https://github.com/amoyano/fennec-releases/releases/latest). Open it and drag Fennec to Applications.

Access is by invitation. Learn more at [heyfennec.com](https://heyfennec.com). Support: help@heyfennec.com.
